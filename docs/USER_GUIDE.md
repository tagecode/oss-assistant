# OSS 助手 - 用户指南

## 快速开始

### 1. 安装应用

从发布页面下载对应平台的安装包：

- Windows: `oss-assistant-x.x.x-setup.exe`
- macOS: `oss-assistant-x.x.x.dmg`
- Linux: `oss-assistant-x.x.x.AppImage`

### 2. 添加云账户

1. 启动应用后，点击「添加账户」
2. 填写账户名称、服务商类型、Access Key ID 和 Secret Key
3. 按服务商要求填写区域或 Endpoint
4. 点击「测试连接」确认凭证有效
5. 点击「保存」

支持的服务商：

| 服务商      | 必填字段                                 |
| ----------- | ---------------------------------------- |
| 七牛云 Kodo | Access Key、Secret Key、区域（z0/z1/z2） |
| 阿里云 OSS  | AccessKey ID、Secret、区域               |
| AWS S3      | Access Key ID、Secret、区域              |
| 兼容 S3     | Access Key、Secret、Endpoint、区域       |

### 3. 浏览文件

1. 在左侧选择账户
2. 选择存储桶
3. 双击文件夹进入子目录
4. 使用面包屑导航返回上级

### 4. 上传文件

- 点击工具栏「上传」按钮选择本地文件
- 或将文件拖拽到文件列表区域
- 上传进度在底部状态栏和任务中心查看

### 5. 下载文件

1. 勾选要下载的文件
2. 点击工具栏「下载」或右键菜单「下载」
3. 选择本地保存目录

### 6. 删除文件

1. 勾选要删除的对象
2. 点击「删除」或按 `Delete` 键
3. 在确认对话框中核对对象列表后确认

## 快捷键

| 快捷键         | 操作         |
| -------------- | ------------ |
| `Ctrl/Cmd + U` | 上传         |
| `Ctrl/Cmd + D` | 下载         |
| `Delete`       | 删除选中     |
| `F5`           | 刷新当前目录 |

## 任务中心

点击底部状态栏的任务摘要打开任务中心，可查看：

- 上传/下载进度、速度、剩余时间
- 任务状态：等待、进行中、成功、失败、已取消
- 取消进行中的任务
- 重试失败的任务
- 清理已完成记录

## 设置

通过右上角设置图标调整：

- 主题：跟随系统 / 亮色 / 暗色
- 默认下载路径
- 上传/下载并发数（1-10）
- 操作日志保留天数
- 自动检查更新

## 帮助与诊断

通过右上角帮助图标：

- 查看常见错误说明
- 查看服务商配置指引
- 导出脱敏诊断日志（用于问题排查）

## 安全说明

- 凭证使用系统加密能力保存在本机，不以明文存储
- 诊断日志和错误提示均经过脱敏处理
- 建议定期轮换 Access Key

## 常见问题

**连接测试失败？**
检查 Access Key 是否正确、区域是否匹配、网络是否可达。

**上传很慢？**
在设置中适当提高并发数；检查网络和服务商限流。

**看不到存储桶？**
确认账户有对应存储桶的读取权限。
